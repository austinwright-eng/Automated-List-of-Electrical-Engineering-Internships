# Utah employer expansion

Verified October 23, 2026 UTC (October 22 in Utah). This first batch adds five
public boards to `data/companies.ee.json`. The upstream registry and collectors
remain unchanged; `role_scope: ee` already unions this overlay at collection time.

This is employer coverage, not a Utah-only location filter. An employer's board
can include other states or countries; normal EE, internship, and US filters still
apply. A working board does not imply a currently eligible internship.

Each board was followed from the employer's official website, checked against
the base registry for duplicate identities, and fetched with the existing
connector. All five connector snapshots reported `complete=True`. Workday was
also checked with an empty search and the collector's `intern` and `co-op` terms.
Search counts are deliberately omitted: Workday searches can match unrelated
words or return all jobs, so those counts are not internship counts.

No published job data, timestamps, or collection statistics are regenerated by
this change. These sources join the next explicitly enabled collection after
merge. Automatic publishing remains controlled by `ENABLE_PUBLISHING`.
